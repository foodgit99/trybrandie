# Competitor Digest PDF Export

Add an **Export PDF** button to the Competitors tab in `/hub` that generates a shareable, branded report of the current competitor landscape and the "steal-the-angle" content ideas Brandie has surfaced.

## What the user gets

A one-click PDF download (`Brandie-Competitor-Digest-YYYY-MM-DD.pdf`) containing:

1. **Cover** — brand name, logo, report date, week window.
2. **Executive summary** — number of competitors tracked, signals this week, ideas generated.
3. **Per-competitor section** — logo, name, domain/IG, last scanned date, discovery rationale, and this week's signals grouped by type (Steal the angle / SEO win / Positioning shift).
4. **"What to steal" ideas** — the linked `content_ideas` rows (title, category, rationale, scheduled day) so the team can act on them outside the app.
5. **Footer** — "Generated by Brandie" + link back to the Hub.

## Where it lives

- Button placed in the Competitors tab header next to **Run digest**, disabled when there are 0 competitors.
- A small loading state ("Preparing report…") while the PDF renders.

## Technical approach

Client-side generation using `jspdf` + `jspdf-autotable` (small footprint, no server round-trip, no edge function cost). Keeps the flow instant and avoids adding a new function.

### Files to add/edit

- **`src/lib/competitorDigestPdf.ts`** *(new)* — pure function `buildCompetitorDigestPdf({ brand, competitors, signals, ideas })` that returns a `jsPDF` doc. Handles typography (Brandie warm neutral palette — Beige/Charcoal/Gold), page breaks, and embedding competitor logos as data URLs (fetched then base64'd; skip on CORS failure).
- **`src/components/v2/hub/CompetitorsTab.tsx`** — add `Export PDF` button, fetch the linked `content_ideas` (title, content_category, funnel_rationale/competitor_rationale, scheduled_for) for `signal.content_idea_id` values, call the builder, trigger `doc.save(...)`.
- **`package.json`** — add `jspdf` and `jspdf-autotable`.

### Data already available on the tab

- `competitors` (from `brand_competitors`)
- `signals` (from `competitor_signals`, last 50)
- Brand info via the existing `brand` prop; extend to pull `name` + `logo_url` from `brands` for the cover.

### Edge cases

- No signals yet → PDF still generates with just the competitor roster and an "Ideas will appear after your first digest" note.
- Logo fetch fails → fall back to initial-letter tile (matches on-screen behavior).
- Long rationales → autoTable handles wrapping; cap each cell at ~500 chars.

## Out of scope

- Server-side rendering / email delivery of the PDF (can be a follow-up).
- Branding customization beyond the existing palette.
- Historical digests (only current week's signals, matching what the tab already shows).
